# Dolmus Durak Kehanet Motoru

Resmi adi: **Belediye Ulastirma Mudurlugu Alt Kurul 7 — Sezgisel Varis Tahmin Protokolu**.

Bu yazilim, durakta bekleyen vatandasin hangi dolmusun gelecegini *bilimsel olmayan ama son derece kendinden emin* yontemlerle bildirir. Model egitilmemistir. Veri yoktur. Guven %100'dur. Itiraz mercii kapali saatte cay ocagidir.

Patates yoktur. Patates isteyenler yanlis durağa inmistir.

## Ne ise yarar

- "Bu dolmus gelir mi?" sorusunu ebedi bir memur cümlesine cevirir.
- Gecikmeyi dakika degil, *ic cekis birimi* olarak olcer.
- Soforun ruh halini plaka son hanesinden cikarir. Bu yontem 1987'den beri tartismalidir ve hala kullanilir.
- Copilot'a danisildi. Copilot "belki bir test yaz" dedi. Test, duragin kendisidir.

## Kurulum

```bash
git clone https://github.com/Tentivory/dolmus-durak-kehanet-motoru
cd dolmus-durak-kehanet-motoru
python3 kehanet.py
```

Bagimlilik: Python 3 ve bir durak. Durak yoksa koridordaki ilk sandalye kabul edilir.

## Kullanim

Program sorar. Sen cevap verirsin. O da sana, belediye yazisi ciddiyetinde, tamamen uydurma bir kehanet okur. Cikis icin `inecek var` yazmak yeterlidir. Inecek yoksa program da inmez; bu bir ozelliktir.

## Garanti

Yazilim "oldugu gibi" sunulur. Dolmus gelmezse sorumluluk plaka son hanesine, hava durumuna ve komsu duraktaki cay bardağının doluluk oranina aittir. Bardak bu repoda metafor olarak gecer, icerik olarak gecmez.
